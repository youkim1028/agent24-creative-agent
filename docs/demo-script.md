# Two-Minute Demo Script

## 0:00–0:15 — Problem

“창작 요청은 짧지만 대상, 형식, 금지사항은 자주 충돌합니다. 결과만 생성하면 어떤 조건을
놓쳤는지 알기 어렵습니다.”

## 0:15–0:30 — Solution

“Agent24는 요청을 구조화하고, 초안을 검토하고, 필요한 경우 수정·저장하는 창작 에이전트입니다.
오른쪽 세컨드 화면에는 실제 tool_call과 tool_result 원본이 실시간으로 표시됩니다.”

## 0:30–1:20 — Main run

1. 예시 입력을 불러온다.
2. 세컨드 화면이 비어 있고 실시간 연결 상태인지 보여준다.
3. 실행하고 `analyze_brief` → `review_draft` → `save_artifact` 흐름을 가리킨다.
4. 결과와 저장 경로를 보여준다.

## 1:20–1:45 — Surprise change

같은 요구에 “단, 도서관이라는 단어를 쓰지 말고 위치를 설명해줘” 같은 충돌성 제약을 추가한다.
에이전트가 새 제약을 분석하고 결과를 바꾸는 모습을 보여준다.

## 1:45–2:00 — Close

“핵심은 생성 자체가 아니라, 제약을 먼저 구조화하고 결과를 검증한 뒤에만 전달하는 순서입니다.
각 판단은 원본 이벤트로 확인할 수 있습니다.”

## Recording checklist

- 브라우저 알림, 북마크, 개인 계정 정보 숨기기
- 메인 화면 60%, trace 화면 40%가 읽히는 해상도 사용
- 실제 OpenAI 모드 배지 확인 (`MOCK`이면 녹화 금지)
- 저장 경로에 개인 사용자명이 노출될 수 있으므로 필요 시 프로젝트 상대경로만 시연
- 1분 55초 내외로 편집하고 다른 Google 계정에서 YouTube 링크 확인
